---
title: "Installation"
description: "Install the uniac CLI."
---

```bash
npm i -g @uniac/cli
```

`@uniac/cli` is a JS shim that resolves to a platform-specific package
containing the Go binary. npm installs the matching one based on your `os` and
`cpu`. Node 18 or newer is required.

Users on platforms without a prebuilt binary (anything other than darwin/linux
× arm64/x64) can grab a tar.gz from the
[releases page](https://github.com/uniac-ai/Uniac/releases) and put `uniac` on
`$PATH` manually.

## Verify

```bash
uniac version
```

```text
uniac 0.3.8 (commit d2706c7, built 2026-08-03T06:57:07Z)
```

## Docker

`uniac deploy` needs a running Docker daemon: it pulls your declared image
locally using your own Docker credentials, then pushes it to the project
registry. Every other command — including `uniac plan` — works without Docker.
