---
title: "Log in"
description: "Authenticate the uniac CLI."
---

```bash
uniac auth login
```

The CLI opens a browser to complete the sign-in flow and writes the session to
`~/.uniac/auth.json` (mode 0600). Keep that file private — anyone with it can
deploy on your behalf.

## Headless machines

```bash
uniac auth login --no-browser
```

Prints the login URL instead of opening a browser; open it on another device
and complete sign-in. With `--manual`, the CLI also skips its local callback
server — paste the redirected URL back into the terminal.

For fully non-interactive use (CI, agents), skip login entirely and set
`UNIAC_ACCESS_TOKEN` — see [Headless operation](/guides/headless).

## Inspect or log out

```bash
uniac auth status     # who is signed in, and until when
uniac auth token      # print the access token, for scripts
uniac auth logout     # delete the stored session
```
