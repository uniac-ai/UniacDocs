The web dashboard at [uniac.ai](https://uniac.ai) is where you create
projects, see what's deployed, and operate live services. It shows the same
per-service account as [`uniac status`](/cli/status) — version, status,
endpoints — and covers what the CLI deliberately does not: removing a service
and scaling replicas.

## Surfaces

| Surface   | What you do there                                                      |
| --------- | ---------------------------------------------------------------------- |
| Projects  | Create projects; rename or delete existing ones.                       |
| Services  | View services within a project; remove a service.                      |
| Instances | See running instances for a service; scale by setting target replicas. |
| Account   | Sign in, sign out, manage billing.                                     |

Everything in the dashboard is also available via the
[Platform API](/platform-api/overview).
