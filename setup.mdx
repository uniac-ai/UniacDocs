Build and run web apps, websites, agents, databases and background workers
on Uniac, the cloud platform for AI agents. Machine setup installs the
Uniac skill for the coding agent, makes the `uniac` command available, and
connects it to the user's Uniac account. Project creation and application
deployment are separate tasks.

The setup commands require Node 18+.

## Agent knowledge

### Claude Code

```sh
npx -y skills@1.5.15 add uniac-ai/agent-skills -g -a claude-code -y
```

### Codex

```sh
npx -y skills@1.5.15 add uniac-ai/agent-skills -g -a codex -y
```

### Cursor

```sh
npx -y skills@1.5.15 add uniac-ai/agent-skills -g -a cursor -y
```

Each command installs the `uniac` skill globally for the named agent and
answers the installer's prompts. Repeating it updates the installed skill.
Additional integrations are listed in the installer's
[supported agents](https://github.com/vercel-labs/skills/tree/v1.5.15#supported-agents).

The [uniac skill](https://github.com/uniac-ai/agent-skills/blob/main/skills/uniac/SKILL.md)
gives the agent a working model of Uniac — composition, deployment, platform
behavior and CLI operation — and links to these pages for complete contracts.

## CLI

The npm package installs the `uniac` command:

```sh
npm install -g @uniac/cli
```

## Account access

```sh
uniac auth login
```

Sign-in requires the user's browser interaction, with account creation
available there. Credential storage, renewal, and platform selection are
described in the
[authentication reference](/cli/authentication).

## Setup state

| Command | Information available |
|---|---|
| `npx -y skills@1.5.15 list -g --json` | Installed skill names, paths, and associated agents. |
| `uniac version` | Version of the CLI available on PATH. |
| `uniac auth status` | Locally stored account sessions and expiry. |

The website has a [quickstart walkthrough](https://docs.uniac.ai/quickstart)
and a [documentation index](https://docs.uniac.ai/llms.txt) listing its pages.
When sign-in or a deployment fails, [Getting help](/cli/output#getting-help)
names the Uniac Discord community and the support email address.
