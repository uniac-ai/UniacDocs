---
title: "Uniac"
description: "Describe a system in one file; the platform runs it."
---

Uniac is a cloud deployment platform. You describe a system of container-based
services in one `uniac.yaml`, the `uniac` CLI resolves it into a deployable
artifact, and the platform runs it — injecting each service's resolved
environment, placing containers on a private network addressable by service
name, and allocating public addresses for whatever you claim. Nothing of
Uniac ships inside your image.

The CLI is built agent-first: offline verification, deterministic artifacts,
typed exit codes, machine-clean output.
