title: "Quickstart"
description: "Scaffold, plan, and deploy your first Uniac service."
---

By the end you will have a container deployed and reachable at a public URL.

## Prerequisites

- Node 18 or newer (to install the CLI via npm)
- Docker, running (for `uniac deploy`)
- A prebuilt container image to deploy — Uniac deploys images, it does not build them

## 1. Install the CLI

```bash
npm i -g @uniac/cli
```

## 2. Log in

```bash
uniac auth login
```

This opens a browser to complete the sign-in flow and stores a token in
`~/.uniac/auth.json`.

## 3. Scaffold a manifest

```bash
uniac init
```

`uniac init` asks for a service name and writes `uniac.yaml`: one service plus
the deployment that instantiates it. Set `image` to your own, or keep the
scaffold's `nginx:alpine` to try the flow:

```yaml uniac.yaml
runtime: yaml
default: main
resources:
  hello:
    type: service
    image: nginx:alpine
  main:
    type: deployment
    services:
      hello:
        from: hello
        public_ports: [{ port: 80, type: http }]
```

## 4. Preview the deployable

```bash
uniac plan
```

`plan` runs fully offline — no network, no credentials, no Docker — and prints
what would ship:

```text
Deployment: main
Artifact:   sha256:2e462d2fe307

Building
  pull nginx:alpine

Deploying
  hello  nginx:alpine  public: 80 (http)
```

Run it after every manifest edit; a manifest that fails `plan` fails `deploy`
with the same error.

## 5. Deploy

```bash
uniac link
uniac deploy
```

`uniac link` binds the directory to a remote project — pick one from the list
or create one. `uniac deploy` pulls the image with your local Docker, pushes it
to the project registry, registers the deployment, and watches until it
settles. The run ends with the state block:

```text
project  my-app-e5f6g7h8

service  hello  v1
  image  nginx:alpine
  digest  sha256:…
  status  running (1/1)
  endpoint  https://<allocated-host>.svc.uniac.ai → :80
```

Open the `endpoint` address in a browser — that's your service.

## 6. Observe

```bash
uniac status
```

Reports what the project is running right now, in the same shape as the deploy
output. Run it any time; it changes nothing.
