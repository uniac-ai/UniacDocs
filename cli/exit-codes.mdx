---
title: "Exit codes"
description: "CLI exit codes and their meanings."
---

| Code | Meaning |
| ---- | ------- |
| 0    | Success |
| 1    | Generic error |
| 2    | Usage error (bad flags or arguments) |
| 3    | Not authenticated |
| 4    | Network error |
| 5    | Build failed |
| 6    | Deploy failed |
