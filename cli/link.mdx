```bash
uniac link [-C dir] [name|slug]
```

<AuthPrereq />

Binds the project directory to a remote Uniac project, writing the binding to
`.uniac/deploy.json`. With no argument, lists the projects on your account and
prompts; with a name or slug, binds directly.

`uniac deploy` and `uniac status` read the binding to know where to act.

## The binding is environment state

`.uniac/deploy.json` records which remote project *this checkout* deploys to.
It is per-checkout state, not source — gitignore it. A teammate links their
own checkout; CI skips linking entirely and sets `UNIAC_PROJECT_URL` — see
[Headless operation](/guides/headless).

Relink at any time to point the directory at a different project; a second
environment is a second project.
