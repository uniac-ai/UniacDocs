---
title: "uniac init"
description: "Scaffold a new uniac.yaml."
---

```bash
uniac init
```

Asks for a service name (default: the directory name), shows the manifest it
is about to write, and creates `uniac.yaml` in the current directory: one
image-sourced service plus the deployment that instantiates it, ready for
`uniac plan`.

```yaml uniac.yaml
runtime: yaml
default: main
resources:
  hello:
    type: service
    image: nginx:alpine  # any OCI image reference
  main:
    type: deployment
    services:
      hello: { from: hello }
```

It refuses to overwrite an existing `uniac.yaml`.

Edit the scaffold — set your image, claim [public exposure](/concepts/endpoints),
add [`env`](/concepts/references) — then verify with [`uniac plan`](/cli/plan).
