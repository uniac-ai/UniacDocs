title: "uniac status"
description: "Report what the linked project is running."

```bash
uniac status [--dir <path>] [service]
```

<AuthPrereq />

Reads what the linked project is running and prints the
[state block](/cli/output). Changes nothing. With a service name, reports that
one service; without, the whole project.

```text
project  my-app-e5f6g7h8

service  web  v4
  image  mendhak/http-https-echo:31
  status  running (1/1)
  endpoint  https://<allocated-host>.svc.uniac.ai → :8080

service  database  v2
  image  postgres:16
  status  running (1/1)
  kind  stateful
```

`deploy` and `status` project the same facts through the same code, so what a
deploy reports and what an observation reports cannot drift into two accounts
of one system. When a deploy's account looks stale or incomplete, `uniac
status` is the authoritative re-read.

A service the project runs appears here whether or not the manifest still
describes it — what is running is not a client's opinion. Retire services from
the [dashboard](/dashboard/overview).
