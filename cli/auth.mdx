---
title: "uniac auth"
description: "Manage the CLI's login session."
---

```bash
uniac auth <login|status|token|logout>
```

| Subcommand | What it does |
|---|---|
| `login` | Complete the browser sign-in flow and store the session in `~/.uniac/auth.json` (mode 0600). |
| `status` | Show who is signed in and when the session expires. |
| `token` | Print the current access token, for scripts and `UNIAC_ACCESS_TOKEN`. |
| `logout` | Delete the stored session. |

Only `login` touches the network; the rest read or delete the local file.

## Login flags

| Flag | Effect |
|---|---|
| `--no-browser` | Print the login URL instead of opening a browser. |
| `--manual` | Skip the local callback server; paste the redirected URL back manually. |
| `--host <host>` | The host serving the `/cli/auth` handoff (default `uniac.ai`, env `UNIAC_AUTH_HOST`). |

For machines that cannot log in at all, set `UNIAC_ACCESS_TOKEN` — see
[Headless operation](/guides/headless).
